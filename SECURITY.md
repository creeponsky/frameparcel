# Security

FrameParcel runs locally inside Figma and declares no network access. It does not use accounts, analytics, external storage, API tokens, or hosted services.

## Reporting a vulnerability

Please use GitHub's **Security** tab to report a vulnerability privately. If private reporting is unavailable, open an issue that describes the affected version and behavior without attaching proprietary design files or exported packages.

## Supported versions

Security fixes are applied to the latest released version.
