# FrameParcel support

Use [GitHub Issues](https://github.com/creeponsky/frameparcel/issues) for bug reports, export compatibility problems, and feature requests.

Please include:

- Figma desktop version and operating system;
- whether you exported the current selection or current Page;
- selected preset;
- node types and approximate number of screens;
- the error shown by FrameParcel or `npm run validate-export`.

Do not attach proprietary Figma files or exported packages unless you are authorized to share them. A minimal reproduction file is preferred.
