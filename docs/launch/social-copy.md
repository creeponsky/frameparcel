## 小红书

### 标题

我把 Figma 设计稿变成了 AI 真能用的离线交付包

### 正文

最近在做 App 大改版时，我踩中了一个很具体的问题：

1. 只导出截图，AI 看得到样子，但不知道真实层级、间距、字体和组件。
2. 只导出 JSON，信息很多，但人和 AI 都很难快速找到真正需要的内容。
3. 每次重新连接 Figma/MCP，会受到账号、调用次数、上下文和工具兼容性的影响。

于是做了一个 Figma 插件：FrameParcel。

现在可以直接选择：

- 一个 Frame / Section / Component
- 多个分散的 Frame
- 一整个 Page

然后一次导出 ZIP。里面包括页面和组件预览、节点结构、真实坐标、字体/颜色/效果、Auto Layout、组件与变量引用、原始图片、去重 SVG、本地浏览页和一份给开发者/Coding Agent 的说明。

它不帮你生成一堆不可维护的代码，而是把正确的设计上下文交给你已有的工程和 Agent。

而且完全本地运行：没有账号、没有 API Token、没有统计分析、没有网络权限。

源码：https://github.com/creeponsky/frameparcel
